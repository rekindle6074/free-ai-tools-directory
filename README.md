# 🚀 Free AI Tools Directory

A curated and high-quality directory of the best free AI tools available today. This project aims to help users find powerful AI solutions for productivity, creativity, coding, and more, without the need for expensive subscriptions.

## 🌐 Live Application
The directory is live and fully functional at:
**[https://free-ai-tools-directory.vercel.app/](https://free-ai-tools-directory.vercel.app/)**

## ✨ Key Features
- **Fast & Responsive**: Built with React and Vite for a lightning-fast user experience.
- **Dynamic Search & Filtering**: Easily find tools by name or category.
- **Performance Optimized**: Integrated with Vercel Speed Insights to ensure top-tier performance.
- **Clean UI**: A modern, minimalist interface designed for clarity and ease of use.
- **Smart Icons**: Automated fallback system for tool icons (Local assets -> High-quality favicons -> Category-based icons).

## 🛠️ Tech Stack
- **Frontend**: React 18, Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Analytics**: Vercel Speed Insights
- **Database (Optional)**: Firebase ready
- **Hosting**: Vercel

## 📂 Project Structure
- `src/`: Main application components and logic.
- `public/icons/`: Directory for tool-specific icons (Format: `{domain}-128x128__Estimated_.png`).
- `metadata.json`: Application metadata and permissions.

## 🚀 How to use locally
1. Clone the repository.
2. Install dependencies: `npm install`.
3. Start the development server: `npm run dev`.
